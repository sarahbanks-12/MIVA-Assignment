## Tools, code and dataset

The schema, SQL fixtures, Python tests, Lua script, diagrams and written explanations were prepared in a Codex session with OpenAI assistance. Anthropic Claude (Claude Code) later audited the package independently, added further tests and corrected scripts and documentation. The synthetic dataset is generated by `seed.sql`; no external dataset was downloaded. Libraries used: psycopg (PostgreSQL client), redis-py (Redis client), ReportLab (PDF generation), PyMuPDF (PDF inspection) and Pillow (diagram rendering). For this first review, `requirements-lock.txt` records only the PostgreSQL client environment. The original psycopg 3.3.8 pin was not installable with the available Python 3.9 interpreter; the reviewed setup uses psycopg 3.2.13 instead.

No third-party project code was copied into the portfolio. The linked database documentation informed the explanations and use of database features. No claim is made that the generated writing, code or reflection is unaided student work.
